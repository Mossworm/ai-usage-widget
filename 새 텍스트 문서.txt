윈도우의 위젯패널에서 볼 수 있는 ai agent의 사용량을 보여주는 위젯을 만들꺼야
위젯은 default window widget 처럼 기본 윈도우의 라이트모드와 다크모드의 테마를 따르도록 할꺼야

위젯 레이아웃은 window layout.png처럼 만들어주고 setting 버튼을 누르면 widget layout setting.png 처럼 어떤 ai or ai api usage를 사용할껀지
토글로 활성화 할 수 있도록 할꺼야

기능은 딱 widget layout.png에만 있는 기능만 있으면돼

최상위 버튼 (Status \ Setting) Logs는 일단 만들지 말고 버튼 두개만 만들어줘

Staute 를 누를경우 window layout 창이 뜸
Setting을 누를경우 widget layout setting 창이 뜸

[Status 창]

3. 주간 한도 - 리셋 시간
